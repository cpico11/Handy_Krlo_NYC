# Handy KRLO NYC Website

Responsive, multi-page handyman website using the Handy KRLO NYC black, white, and slate-blue brand palette.

## Pages
- `index.html` — Home
- `about-us.html` — About Us
- `services.html` — Services
- `gallery.html` — Gallery / project photos
- `reviews.html` — Reviews
- `locations.html` — Locations We Serve
- `contact-us.html` — Contact Us

## Files
- `assets/styles.css` — shared design and horizontal navigation
- `assets/logo.jpg` — business logo
- `assets/main.js` — mobile navigation and contact form helper

## Before launch
1. Replace the sample phone number and email address in `contact-us.html`.
2. Update service locations to match the areas actually served.
3. Replace review placeholders with genuine customer reviews.
4. Connect the contact form to a form service or WordPress form plugin. The static demo opens a prefilled email only after the business email is configured.
5. For WordPress, either use these files as a custom theme/static page source or copy page content into WordPress pages and load the shared stylesheet separately.

## GitHub Pages
In repository Settings → Pages, choose the `main` branch and `/(root)` as the publishing source.
